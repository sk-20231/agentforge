# Upper bound is deliberate. mcp 2.0.0 is a breaking major release (it renamed
# McpError -> MCPError, among other changes) and this code has only ever been
# tested against 1.x. Without the bound, a fresh clone installs 2.x and the
# repo is broken on arrival for everyone but the maintainer, whose venv predates
# the release. Raise it on purpose, after testing, not by accident.
mcp[cli]>=1.0.0,<2.0.0

# declares langchain-core with no upper bound, and today only a sibling
# package's ceiling keeps a future 2.x out. Don't rely on someone else's pin.
# LangSmith tracing stays off unless LANGSMITH_TRACING=true is set.
